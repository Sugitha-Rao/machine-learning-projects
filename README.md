# Machine Learning 

This repository contains my learning journey through **Machine Learning** and **Deep Learning** concepts.  
I explore core algorithms from scratch and using libraries like `scikit-learn`, `pandas`, and `tensorflow/keras`.

---

## Topics Covered

- **Regression**
  - Linear, Polynomial, and Ridge/Lasso Regression
- **Classification**
  - Logistic Regression, SVM, Decision Tree, Random Forest, KNN
- **Clustering**
  - K-Means, Hierarchical, DBSCAN
- **Deep Learning Basics**
  - Perceptron, Feedforward Networks, Keras-based Models

---

## Tech Stack
- Python 
- NumPy, Pandas, Matplotlib, Seaborn
- Scikit-learn
- TensorFlow / Keras (for basic NN)
- NLP with NLTK
