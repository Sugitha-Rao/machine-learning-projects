# Dataset - Melbourne Housing

This repository contains the Melbourne Housing Market Dataset, which includes property sales information from Melbourne, Australia.
This dataset is commonly used for regression, EDA, and real-estate price prediction models.

**Dataset Overview**
Rows: 34,857
Columns: 22
Prediction Target: Price (house sale price)
Many columns contain missing values, making this dataset ideal for practicing data preprocessing.

**Dataset Description**
The dataset includes the following columns:
| Column        | Description                                                   |
| ------------- | ------------------------------------------------------------- |
| Suburb        | Suburb name                                                   |
| Address       | Property address                                              |
| Rooms         | Number of rooms                                               |
| Type          | House type (h = house, u = unit, t = townhouse, etc.)         |
| Method        | Sale method (S = sold, SP = sold prior, PI = passed in, etc.) |
| SellerG       | Selling agent                                                 |
| Date          | Date of sale                                                  |
| Distance      | Distance from CBD (km)                                        |
| Postcode      | Postal code                                                   |
| Bedroom       | Number of bedrooms                                            |
| Bathroom      | Number of bathrooms                                           |
| Car           | Number of car spots                                           |
| Landsize      | Land area (m²)                                                |
| BuildingArea  | Building area (may contain mixed types)                       |
| YearBuilt     | Year property was built                                       |
| CouncilArea   | Local government council                                      |
| Latitude      | Latitude                                                      |
| Longtitude    | Longitude                                                     |
| Regionname    | Region classification                                         |
| Propertycount | Number of properties in the suburb                            |
| ParkingArea   | Parking area (may contain text/missing)                       |
| Price         | **Target column** (house price)                               |
